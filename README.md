# Doodle Duel
n**Play:** https://doodle.sagar-gavand.co.in

A mobile-first multiplayer draw-and-guess party game. One player draws, everyone else races to guess the word in chat.

- No server: players connect peer-to-peer over WebRTC (PeerJS public broker for signaling). The room creator's browser is the host, so keep that tab open.
- Create a room, share the link, play 2–10 players.

Static site: `index.html` + `vercel.json`.
